# Why Surf is free and open source

AI is opening up remarkable new possibilities for what one person can do.

I want as many people as possible to experience that. This is why Surf is free.

There are no paid tiers and no fee for moving further. If you're willing and ready to
learn, money should not decide how far Surf will help you go.

Open source follows from the same idea. Agency isn't only about what you are able to do;
it is also about being able to understand and shape the tools that help you get there.

Surf's code and learning framework are open for anyone to read. You can understand how it
works, challenge it, change it or take it somewhere I never imagined.

There is something optimistic to me about that. A powerful new technology is arriving,
and people everywhere are discovering what it can make possible. An open learning method
can travel further than any one person or organisation could imagine.

Surf is free because everyone deserves the chance to get in the water. It is open source
because the way it works should belong in the open.
